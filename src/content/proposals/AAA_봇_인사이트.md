# 봇 인사이트

> 이 파일은 `/analyze N` 실행 시 AI가 인사이트를 누적 추가합니다.

## 프로젝트 아이디어

### W20 신규

1. **크로스 채널 콘텐츠 자동 리사이징** — 롱폼 1개를 쓰레드/인스타/유튜브/틱톡용으로 자동 변환. 현재 수동으로 각 채널에 맞게 편집하고 있어서, 이걸 자동화하면 콘텐츠 생산량을 2~3배 늘릴 수 있다.

2. **페르소나별 성과 A/B 테스트 프레임워크** — 정명희, 서하윤, 한지호 등 여러 페르소나가 동시 운영 중. 어떤 페르소나가 어떤 채널에서 성과가 좋은지 체계적으로 비교할 수 있는 대시보드.

3. **팀 콘텐츠 캘린더 자동 생성** — 각 멤버의 데일리 투두에서 콘텐츠 관련 항목을 추출하여, 팀 전체 콘텐츠 발행 스케줄을 자동으로 만들기. 채널 간 충돌이나 공백을 미리 발견 가능.

### W21 신규

1. **Claude CLI 팀 공용 프롬프트 라이브러리** — Erin이 스크립트→자막 워크플로우를, Ellie가 노션 자동화를 각자 구축 중. 이 프롬프트들을 공유 저장소에 모으면 학습 곡선 없이 팀 전체가 즉시 활용 가능.

2. **설문 데이터 기반 광고 소재 자동 생성** — 그로스헬퍼 설문 분석 결과(리드 전환율 높음)를 자동으로 광고 카피·크리에이티브로 변환. "설문 결과 → 인사이트 카드 → 광고 소재"까지 파이프라인화하면 마케팅 소재 수급이 빨라진다.

3. **R&D 발표 준비 키트 자동화** — Ian이 1주일에 3건의 발표평가를 소화. 발표 자료의 공통 구조(비즈니스 모델·지표·로드맵)를 템플릿화하고, 노션/옵시디언의 최신 데이터를 자동 삽입하면 준비 시간을 대폭 줄일 수 있다.
