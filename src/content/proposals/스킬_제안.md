# 스킬 제안

## 제안 목록

### #1. SNS 게시물 자동 점검 대시보드 (W20)

- **배경**: "자동화 게시물 점검"이 5일 연속 투두에 등장. 수동으로 각 채널을 돌아다니며 확인 중
- **제안**: 쓰레드/인스타/유튜브/틱톡 게시 상태를 한 화면에서 확인하는 대시보드
- **난이도**: 중급
- **관련 업무**: 콘텐츠 마케팅 전반
- **추천 멤버**: Dana, Erin
- **예상 시간절감**: 일 30분 × 5명 = 주 12.5시간

### #2. 영상 제작 파이프라인 원클릭 자동화 (W20)

- **배경**: 여러 멤버가 "TTS 스크립트 → 일레븐랩스 → AI Studio → Vrew" 동일 워크플로우를 매일 반복

- **난이도**: 고급
- **관련 업무**: 숏폼/롱폼 제작
- **추천 멤버**: Sophie, Erin, Ann
- **예상 시간절감**: 건당 1시간 → 15분으로 단축

### #3. R&D 지원사업 매칭 봇 (W20)

- **배경**: "제목만으로는 우리에게 해당되는 사업인지 식별이 어려움"이라는 버퍼 항목 반복
- **제안**: 지원사업 공고를 자동 수집하고, 인톡 사업 프로필과 매칭도를 판단하는 봇
- **난이도**: 중급
- **관련 업무**: R&D 지원사업 서칭
- **추천 멤버**: Smith
- **예상 시간절감**: 주 3~5시간 서칭 시간 절감

### #4. 노션 분산 자료 자동 아카이빙 (W20)

- **배경**: "노션에 흩어져 있는 자료 위치 확인 요청"이 반복. 사업 지표/로드맵/기술 해자 관련 문서가 산재
- **제안**: 노션 워크스페이스를 스캔하여 카테고리별로 자동 정리 + 옵시디언 아카이빙 연동
- **난이도**: 중급
- **관련 업무**: 사업 문서 관리
- **추천 멤버**: Smith, Sophie
- **예상 시간절감**: 자료 탐색 시간 주 2시간 절감

### #5. Claude CLI 영상 제작 표준 워크플로우 (W21)

- **배경**: Ellie, Erin, Dana가 각자 다른 방식으로 Claude CLI를 영상 제작에 접목 중. 스크립트 작성~자막 삽입까지 CLI 안에서 가능하다는 것이 확인됨
- **제안**: 팀 공통 Claude CLI 영상 제작 워크플로우(프롬프트 템플릿 + 설정값) 표준화. Erin의 "스크립트→자막" 워크플로우를 기반으로 문서화
- **난이도**: 초급
- **관련 업무**: 콘텐츠 마케팅 전반
- **추천 멤버**: Erin, Ellie, Dana
- **예상 시간절감**: 멤버당 일 30분~1시간 (학습 곡선 제거)

### #6. 롱폼 → 멀티채널 자동 변환 파이프라인 (W21)

- **배경**: 롱폼 1건 제작에 2~3시간 소요, 이후 숏폼/쓰레드/인스타/틱톡용으로 수동 변환. Ellie·Erin·Sophie 모두 ⚠️로 표시

- **난이도**: 고급
- **관련 업무**: 롱폼/숏폼 변환, 멀티채널 배포
- **추천 멤버**: Erin, Sophie
- **예상 시간절감**: 롱폼 1건 후속 작업 2시간 → 30분

### #7. 파트너스 전환 UTM 대시보드 (W22)

- **배경**: UTM·링크트리·기능별 랜딩 링크가 세팅되었으나, 어떤 채널→어떤 기능이 실제 가입으로 이어지는지 한 곳에서 볼 수 없음. Sophie가 수익계산기·적합도검사·경험담 기능을 마케팅에 투입하면서 전환 추적이 시급해짐
- **제안**: UTM 파라미터별 파트너스 가입 전환율을 실시간 확인하는 대시보드. Mixpanel 이벤트와 연동
- **난이도**: 중급
- **관련 업무**: 마케팅 → 파트너스 전환 파이프라인
- **추천 멤버**: Sophie, Erin
- **예상 시간절감**: 채널별 성과 수동 집계 주 3시간 → 자동화

- **난이도**: 고급
- **관련 업무**: 숏폼 제작 전 과정
- **추천 멤버**: Erin, Ellie, Sophie
- **예상 시간절감**: 숏폼당 후킹 기획 시간 30분 → 5분
