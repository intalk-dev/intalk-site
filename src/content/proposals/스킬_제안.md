- **배경**: "자동화 게시물 점검"이 5일 연속 투두에 등장. 수동으로 각 채널을 돌아다니며 확인 중

- **관련 업무**: 콘텐츠 마케팅 전반
- **추천 멤버**: Dana, Erin
- **예상 시간절감**: 일 30분 × 5명 = 주 12.5시간

### #2. 영상 제작 파이프라인 원클릭 자동화 (W20)

- **배경**: 여러 멤버가 "TTS 스크립트 → 일레븐랩스 → AI Studio → Vrew" 동일 워크플로우를 매일 반복

- **추천 멤버**: Sophie, Erin, Ann
- **예상 시간절감**: 건당 1시간 → 15분으로 단축

### #3. R&D 지원사업 매칭 봇 (W20)

- **배경**: "제목만으로는 우리에게 해당되는 사업인지 식별이 어려움"이라는 버퍼 항목 반복

### #4. 노션 분산 자료 자동 아카이빙 (W20)

- **배경**: "노션에 흩어져 있는 자료 위치 확인 요청"이 반복. 사업 지표/로드맵/기술 해자 관련 문서가 산재

- **추천 멤버**: Smith, Sophie
- **예상 시간절감**: 자료 탐색 시간 주 2시간 절감

### #5. Claude CLI 영상 제작 표준 워크플로우 (W21)

- **예상 시간절감**: 멤버당 일 30분~1시간 (학습 곡선 제거)
